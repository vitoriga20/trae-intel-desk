数据备份与恢复

所有数据存于浏览器 localStorage。建议定期导出 JSON 备份；恢复时导入备份文件，或粘贴论坛 API 原始 JSON 兜底。

纯网页也能动态抓取，靠的是公共 CORS 代理。优先级：自建代理 > corsfix 公共代理（默认，已实测可用）> corsproxy.io > allorigins。

当前通道
· 部署在 http(s) 网址下：默认走 corsfix 免注册代理（sdk 免费档），直接点「抓取最新」即可。 · 免费档限制：60 次/分钟、约 10 MB/月流量。已把每次抓取压到 9 页列表 + 少量正文，大约够每月几十次刷新。 · 双击 HTML（file://）打开：浏览器 Origin 为 null，代理会拒绝，此时只能浏览内置快照。 · 想彻底稳定：在下面填自建 Cloudflare Worker 地址（免费，无额度限制）。

可选。免费注册 console.corsproxy.io 后复制 Key 填入。 免费档每月 1 万次、60 RPM，超额或超速会被拒（401/403/429）。

控制抓取时对论坛发送请求的节奏。默认低频，尊重论坛服务；网络/代理不稳时建议保持低频，需要更快的抓取可调高。
